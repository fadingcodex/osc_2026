# OpenSouthCode 2026

[OpenSouthCode](https://www.opensouthcode.org/conferences/opensouthcode2026) es un evento para promocionar y dar a conocer las tecnologías abiertas: software/hardware libre y opensource.

Desde 2016, OpenSouthCode ha sido punto de encuentro de las comunidades de tecnologías abiertas en el sur de Europa.

## Sobre la charla

Es el momento de empezar a hablar de state (para gestionar la información que fluye por las apps), y también de backend (para tratar y almacenar esos datos con los que operas).

Esta charla se impartirá en la edición  2026.
